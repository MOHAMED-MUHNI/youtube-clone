# YouTube Clone

A pixel-perfect YouTube homepage clone built with pure HTML and CSS. This project replicates the look and feel of YouTube's main page, including the header, sidebar navigation, and video grid layout.

## 🎬 Demo

Open `youtube.html` in your browser to view the YouTube homepage clone.

## ✨ Features

- **Fixed Header** - YouTube-style header with:
  - Hamburger menu and YouTube logo
  - Functional search bar with voice search button
  - Create, Apps, and Notifications icons with tooltips
  - User profile picture

- **Sidebar Navigation** - Collapsible sidebar with navigation links:
  - Home
  - Explore
  - Subscriptions
  - Originals
  - YouTube Music
  - Library

- **Video Grid** - Responsive video thumbnail grid featuring:
  - Video thumbnails with duration overlay
  - Channel profile pictures
  - Video title, author, view count, and upload date
  - Responsive layout that adapts to screen size

- **Responsive Design** - Media queries for optimal viewing on different screen sizes:
  - 4 columns on large screens (≥1000px)
  - 3 columns on medium screens (751px - 999px)
  - 2 columns on small screens (≤750px)

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Styling with:
  - Flexbox for header and sidebar layouts
  - CSS Grid for video thumbnail grid
  - Media queries for responsive design
  - Custom tooltips
  - Fixed positioning for header and sidebar
- **Google Fonts** - Roboto font family

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/MOHAMED-MUHNI/youtube-clone.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd youtube-clone
   ```

3. **Open in browser**
   - Simply open `youtube.html` in your preferred web browser
   - Or use a local development server like Live Server in VS Code
